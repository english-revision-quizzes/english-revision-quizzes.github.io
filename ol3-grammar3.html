If / When + present simple, present simple
If / When we mix red and yellow, we get orange. · If I go to bed late, I feel tired.
  • Questions:
    If we mix red and yellow, do we get orange?
    What do we get if we mix red and yellow?

⚠️ Important note

  • Use it for facts, rules and habits that are always true.
  • Both verbs are in the present simple. Do not use will.
  • If and when mean the same here: If / When you heat ice, it melts.
If + present simple, will / won't + infinitive
If he works hard, he will earn a lot of money.
  • Unless = if ... not:
    Unless he works hard, he won't earn a lot. (no "not" after unless)
  • We can use can, may, might, must, should instead of will: If you feel tired, you should stop.
  • Never use will after if: If it rains, the picnic will be cancelled. ✔ (not "if it will rain")
  • Other ways: as long as / providing (that) / provided (that) = if
    in case + present simple (just to be safe)
    without / but for + noun or -ing = unless

⚠️ Important note

  • The if-clause is present simple. The main clause has will. Never put will after if.
  • Unless = if ... not. Do not add another not after unless.
  • Use it for a real, possible future. Think: "This may really happen."
  • in case + present = to be ready for something bad:
    Take an umbrella in case it rains.
If + past simple, would / wouldn't (could / might) + infinitive
If he studied more, he would get better marks. · If people had wings, they would fly.
  • With be use were for all persons: If I were a bird, I could fly.
    If I were you, I'd study hard (advice = you should).
  • If the verb is had + noun or had to: If I had a car, I would drive you.
  • Suppose / Imagine can replace if: Suppose you were in China, what would you eat?
  • If it weren't for + noun / -ing = unless:
    If it weren't for his money, he wouldn't buy it.

⚠️ Important note

  • Use were for all persons: If I were, if he were. (If I were you = advice.)
  • The if-clause is past simple but the meaning is now or the future (unreal or unlikely).
  • The main clause uses would + base verb: never would after if.
  • Exam trap: a verb like read, cut, put may look past or present. Check the main clause: would means it is past form.
If + past perfect, would / could / might + have + past participle
If he had trained hard, he would have won yesterday's match.

⚠️ Important note

  • Use it for an imaginary past: a regret or something that did not happen.
  • The if-clause has had + past participle. The main clause has would have + past participle.
  • Never put would have in the if-clause.
  • It tells you the opposite fact: If he had trained, he would have won = he did not train, so he did not win.
  • Should he help me, I'll do it well. (= If he helps me ...)
  • Were I a good footballer, I would be famous. (= If I were ...)
    Were you to tell me, I would understand.
  • Had I enough time, I would help you.
    Had he left, I would have called him.
Exam trap: if the verb after if is cut, put, hit, shut, read and the subject is he/she/it, look at the time and the main verb. If he read the news, he would know.

⚠️ Important note

  • When you use Should / Were / Had at the start, drop if.
  • Should he help = If he helps (first).
    Were I = If I were (second).
    Had he left = If he had left (third).
  • The rest of the sentence stays the same:
    Should Hamza help me, I'll do it well.
    Were you to tell me, I would understand.
    Had I enough time, I would help you.
  • Without + noun / In case of + noun / Unless + clause: do not mix them up.
