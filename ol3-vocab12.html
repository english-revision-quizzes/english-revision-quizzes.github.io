2. Key idioms

  • caught in a trap = unable to escape from a dangerous or difficult situation
  • put on a friendly face = pretend to be kind, sometimes to hide bad intentions
  • take control of = start controlling or managing something
  • too good to be true = so good that it seems unlikely to be real
  • trust, but verify = believe someone, but check the facts to be safe
  • wolves in sheep's clothing = people who seem kind but are really dangerous

5. Word families

  • betray (v) → betrayed (adj) → betrayal (n) → betrayer (n)
  • deceive (v) → deception / deceit (n) → deceptive (adj) → deceiver (n)
  • exploit (v) → exploited (adj) → exploitation (n) → exploiter (n)
  • interact (v) → interaction (n) → interactive (adj) → interactively (adv)
  • reputation (n) → reputable / reputed (adj) → reputedly (adv) · disrepute (n)
  • scam (n, v) → scammer (n) · support (v, n) → supportive (adj) → supportively (adv)
  • tactic (n) → tactical (adj) → tactically (adv)

6. Clear the confusion

  • affect (verb: to change) / effect (noun: a result)
  • be caught in a trap (be stuck) / set a trap (prepare it for someone)
  • cloth = material or a piece of material · clothing = clothes in general (uncountable) · clothes = things we wear (plural)
  • lend = give for a short time · borrow = take for a short time
  • lie, lied, lied = say what is not true · lie, lay, lain = rest flat · lay, laid, laid = put something down; birds lay eggs
