4. Verb + preposition

5. Word families

  • aware (adj) → awareness (n) → unaware (adj)
  • defend (v) → defender (n) → defense / defence (n) → defensive (adj) → defensively (adv)
  • visible (adj) → invisible (adj) → invisibly (adv) → invisibility (n)
  • ruin (v, n) → ruined (adj) · rumor (n, v)

6. Useful patterns

  • find + object + adjective: I find the exam difficult.
  • help + object + infinitive (with or without to): My teacher helped me understand / to understand the lesson.
